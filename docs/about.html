关于这份源码笔记

这是 Yuli-yx 的个人技术学习网站，记录 vLLM、vLLM-Ascend 与推理系统实现的阅读和理解。

内容与证据

每篇注明源码快照。MRV2 单元基于 2026-10-16 的版本；KV cache 专题基于 2026-10-23 核对的版本。日期代表材料核对时间，不代表最新主线，也不证明两份源码的运行兼容性。

代码来自公开 GitHub 仓库对应 commit，页面保留节选与原始行号。文字解释、软件设计分析和手算示例是学习整理；实测结论会另外说明环境与证据。打开页面或完成自动检查不会被视为学习掌握。

网站不收集个人学习记录；搜索和计算器在浏览器本地执行。课程工作笔记、机器信息和本地运行文件不属于公开内容。

阅读方式

先跟例子，再展开代码，最后合上材料复述对象的输入、输出和归属。比较不同版本时，先确认调用点和 patch，再讨论行为。

对某段实现有疑问，可以记录层名、group ID、调用路径与具体版本，再继续查证。

源码归属

vLLM 与 vLLM-Ascend 源码节选保留在原项目的 Apache-2.0 许可下。参见 第三方说明 和 许可证文本。本站不是项目官方文档。
