跟一个 800-token 请求走完 P → D

本例实际逻辑 block=640。Flash 的 stateful 路径沿用 CPD 的最后 token 重算：P 计算前 799 tokens，D 恢复它们，再计算最后一个 prompt token。不是用户重复发送两次请求，也不是两个独立的回答。proxy 内部转发 P、D 两个阶段。

P 计算与入池逐层 ready → 后台 copy → step drain → 发布
→
共享 MemCache完整块 + PD 尾块 + 精确状态
→
D 整体恢复本地 block IDs → GET → finished_recving

数据经池传递；控制另走 P response → 原 proxy 透传 → D request。租约和完成事件管理资源，不通过 proxy 搬运 cache 字节。

改变 prompt 长度，查看交接组成

演算适用于此处 stateful N−1 路径。1-token 等短请求由实际分支处理，不套用本控件的分块假设。

  1. P / PoolPDScheduler.on_new_request()

    保存原始 prompt 长度和摘要，再调用截断 helper，保留 D 重算最后 token 的契约。

  2. P / KVPoolScheduler

    普通前缀查找、完整块读写继续由池化调度。完整块不必等整个 prompt 结束；最终 PD 尾块和精确状态在最后 chunk 到达交接边界时下发。

  3. P / PoolPDWorker.prepare() → save_layer()

    生成对象与 session，每层就绪后提交原 layerwise 发送队列。799 tokens 对应 640 完整块、159 attention 尾部和 799 边界的 KDA/环形状态。

  4. P / wait_for_save() → finish()

    排空所有完整块与尾状态复制，发布对象，回传 checkpoint 完成事件。成功结果交回调度侧后，request_finished 才提供 handoff。

  5. Proxy

    沿用原 examples/disaggregated_prefill_v1/load_balance_proxy_server_example.py，透传 kv_transfer_params。

  6. D / get_num_new_matched_tokens() → update_state_after_alloc()

    检查协议、原始长度、MTP 数；申请外部恢复范围 N−1 减去本地已命中长度，拿到 D 自己的 block IDs。

  7. D / PoolPDWorker.start_load()

    根据请求与布局重建 key，整体恢复所有必需组件，成功后报告 finished_recving。随后 runner 执行最后 token 和本地 draft 初始化。

    def get_num_new_matched_tokens(self, request, num_computed_tokens):
        self.requests[request.request_id] = request
        self.pd_load_requests.discard(request.request_id)
        params = request.kv_transfer_params or {}
        if not params.get("do_remote_prefill"):
            return self.pool.get_num_new_matched_tokens(request, num_computed_tokens)
        if params.get("pool_pd_protocol") != POOL_PD_PROTOCOL:
            raise ValueError("Pool PD receive requires a compatible completed producer handoff")
        remote_mtp = params.get("pool_pd_mtp_tokens", 0)
        if type(remote_mtp) is not int or remote_mtp != self.mtp_tokens:
            raise ValueError("Pool PD requires matching P/D speculative token counts")
        length = len(request.prompt_token_ids or ())
        if params.get("remote_num_prompt_tokens") != length:
            raise ValueError("Pool PD handoff prompt length differs from the decode request")
        # Keep the existing CPD last-token recomputation. Draft cache is local.
        count = max(0, length - 1 - num_computed_tokens)
        if count:
            self.pd_load_requests.add(request.request_id)
        self.matches[request.request_id] = num_computed_tokens
        return count, count > 0

    def start_load(self, metadata):
        self.transfer.start_load(metadata.pool)
        for request in metadata.receives:
            session = None
            try:
                session = self.transfer.io.begin(self._plans(request, tail_only=False, writing=False), writing=False)
                self.transfer.io.copy(session)
                self.transfer.io.finish(session)
                logger.info(
                    "Pool PD GET req=%s cache_tokens=%s objects=%d bytes=%d",
                    request.request_id,
                    request.cache_tokens,
                    len(session.plans),
                    sum(plan.size for plan in session.plans),
                )
            except Exception:
                # Eviction between P completion and D acquisition is a miss,
                # not permission to consume partly restored cache.
                logger.exception("Pool PD receive failed for %s", request.request_id)
                self.results.failed_recving.add(request.request_id)
            finally:
                if session is not None:
                    self.transfer.io.abort(session)
            self.results.finished_recving.add(request.request_id)

    def request_finished(self, request, block_ids):
        params = request.kv_transfer_params or {}
        if params.get("do_remote_decode") and request.status == RequestStatus.FINISHED_LENGTH_CAPPED:
            if request.request_id not in self.tail_scheduled:
                raise RuntimeError("Cannot hand off a prompt without its pool publication step")
            # wait_for_save completed before this model result was delivered.
            # Objects remain in the pool; no HBM hold or remote delete ACK.
            handoff = {
                "do_remote_prefill": True,
                "do_remote_decode": False,
                "pool_pd_protocol": POOL_PD_PROTOCOL,
                "remote_num_prompt_tokens": self.original_prompts.get(
                    request.request_id, (len(request.prompt_token_ids), None)
                )[0],
            }
            if self.need_truncate or self.mtp_tokens:
                # This verifies the cache contract, not draft work requested
                # from D. Each endpoint initializes its own draft state.
                handoff["pool_pd_mtp_tokens"] = self.mtp_tokens
            logger.info(
                "Pool PD handoff req=%s prompt_tokens=%d cache_tokens=%d",
                request.request_id,
                handoff["remote_num_prompt_tokens"],
                len(request.prompt_token_ids),
            )
            return False, handoff

    def partial_objects(self, start: int, block_id: int, digest: str, valid_tokens: int) -> tuple[PoolObject, ...]:
        """PD-only compact tail, preserving the full object's component order.

        Upstream fixed-chunk templates include invalid tail bytes. Slice each
        validated head/token view instead; shard ownership stays upstream's.
        No ordinary-prefix lookup ever requests this key namespace.
        """
        if self.state or not 0 < valid_tokens < self.chunk_size:
            raise ValueError("Partial objects require an incomplete attention chunk")
        if not 0 <= block_id < self.num_blocks or start < 0 or start % self.chunk_size:
            raise ValueError("Invalid partial object boundary")
        result = []
        for shard_index, shard in enumerate(self.local_shards):
            ranges, cursor = [], 0
            for owner, parts in self.component_views.items():
                for component, view in parts:
                    heads = view.shape[2] // len(self.local_shards)
                    for head in range(shard_index * heads, (shard_index + 1) * heads):
                        # Only complete compressed rows are persistent here.
                        # Residual tokens are restored from the PD tail state.
                        ratio = component.tokens_per_state
                        token = int((start % self.block_size) // ratio)
                        stop = int((start % self.block_size + valid_tokens) // ratio)
                        while token < stop:
                            kernel, offset = divmod(token, view.shape[3])
                            count = min(stop - token, view.shape[3] - offset)
                            address = view[block_id, kernel, head, offset].data_ptr()
                            size = count * view.shape[4] * view.element_size()
                            ranges.append(PoolRange(owner, address, cursor, size))
                            cursor += size
                            token += count
            key = self.key(shard, f"partial_{valid_tokens}_{digest}")
            result.append(PoolObject(key, cursor, block_id, tuple(ranges)))
        return tuple(result)

生命周期要守住三道边界

① 计算写完

ready event 保证源数据已产生。由后台线程等待，前台可以继续后续层。

② 传输读完

drain 保证没有在途读取。之前不能覆盖 live state、释放源页或销毁 session。

③ 对象可读

全部 range 完成才能发布；完成 ACK 必须晚于数据完成。

RequestStateLayout.snapshot() 返回的只是源内存范围，并没有 clone。环形页会在后续执行中原地更新；KDA conv/recurrent 同样会变化。block 引用只阻止 allocator 回收，不阻止模型写同一地址。

    def snapshot(self, block_id, digest, cache_tokens):
        if not 0 < block_id < self.num_blocks or cache_tokens <= 0:
            raise ValueError("Circular snapshot requires an allocated block and computed prefix")
        ranges, offset = [], 0
        for owner, base, stride, size in self._components:
            ranges.append(PoolRange(owner, base + block_id * stride, offset, size))
            offset += size
        key = PoolKey(self.metadata, f"pd_state_{cache_tokens}_{digest}").to_string()
        return (PoolObject(key, offset, block_id, tuple(ranges)),)

因此当前采用层间重叠、step 边界排空：本层完成 → 后台复制，同时后续层计算 → 本 step drain → 下一 chunk/step 才可覆盖。共享格式仍拒绝未经验证的跨层 HBM 复用配置，不启用旧路径可选的跨 step 延迟 drain。只有源地址独立且回调真正位于该 owner 最后一次写入之后，这个推理才成立。

生命周期逐步推演
  1. 源状态计算中
  2. 记录事件 / 入队
  3. 后台复制
  4. 排空 / 发布
  5. 完成确认 / 可复用

普通 KDA checkpoint 沿用 scheduler 的引用保护：保留非空、非 speculative scratch block，worker 完成后回传 completed_events，达到预期 worker 数才释放。scratch 不能随意 pin，否则会破坏 allocator 的独占重定位要求。

    def touch_sending_mamba_blocks(self, req_meta: ReqMeta) -> None:
        """
        Keep the reference of all non-null Mamba blocks sent to the external store.
        """
        if not self.use_hybrid or not self.num_speculative_blocks_by_group or not req_meta.can_save:
            return
        # Layerwise transfer frees mamba blocks layer by layer on its own
        # completion path (see KVCacheStoreSendingThread); bulk-touching them
        # here would double-reference the block pool and leak blocks.
        if self.use_layerwise:
            return
        using_event_id = self.get_sending_event_id()
        req_meta.event_id = using_event_id
        current_step_sending: list[int] = []
        for group_id, num_speculative_blocks in self.num_speculative_blocks_by_group.items():
            group_block_ids = req_meta.block_ids_by_group[group_id]
            # The last num_speculative_blocks slots are speculative scratch
            # blocks that the allocator relocates in place; relocation requires
            # them exclusively owned (ref_cnt == 1), so they must never be
            # pinned here (crashes allocate_new_blocks after vllm PR #51358).
            non_spec_block_ids = (
                group_block_ids[:-num_speculative_blocks] if num_speculative_blocks > 0 else group_block_ids
            )
            current_step_sending.extend([block_id for block_id in non_spec_block_ids if block_id > 0])
        logger.debug("event: %s touch blocks: %s", using_event_id, current_step_sending)
        assert self._block_pool is not None
        self._block_pool.touch([self._block_pool.blocks[block_id] for block_id in current_step_sending])
        self.sending_events[using_event_id] = 0
        self.sending_blocks[using_event_id] = current_step_sending

    def drain(self) -> None:
        """Wait for copies before callers publish or release source buffers.

        A failed worker may leave unstarted tasks queued. Join it first so no
        native copy can still read the source, then discard those tasks. The
        caller retains ownership of task resources and receives the failure.
        """
        pending = self.request_queue
        with pending.all_tasks_done:
            while pending.unfinished_tasks and self._fatal_error is None:
                if not self.is_alive():
                    raise RuntimeError(f"{self.name} stopped with pending transfers")
                pending.all_tasks_done.wait(timeout=0.1)
        if self._fatal_error is not None:
            self.join()
            while True:
                try:
                    pending.get_nowait()
                except queue.Empty:
                    break
                pending.task_done()
        self.raise_if_failed()

取消、关闭和异常也先处理在途复制。发送失败会在唤醒 drain 之前记录 fatal error；停止的任务不会发布半成品。租约保护远端对象，源页引用与 drain 保护本地数据，两者不能互相替代。

MTP：共享 target，D 仍然自己算 draft

pool_pd_mtp_tokens 只检查当前 Flash 的缓存兼容性，不是 P 给 D 分配投机任务。MTP=0/1 会改变 target conv 宽度与环形容量，因此本阶段要求 P/D 相同 MTP 数。D 不读取 P 的 draft cache，继续本地初始化。

target/draft 的筛选依据实际 owner。唯一位于 PD/池化之外的产品改动，是 MRV2 在 cache spec 转换与 padding 后传播 is_draft_layer → is_draft。先标记再重建 spec 可能丢失标记；把传播放到转换之后，才能正确排除辅助 indexer 等 draft cache。
