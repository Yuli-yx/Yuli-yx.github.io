01 / 先分索引

四种数字，四种含义。

数字索引谁本例
req_state_idx长期保存的请求状态行C → 1，A → 3
batch_idx本轮请求顺序C → 0，A → 1
positiontoken 在该请求整个序列中的位置C 的本轮 token → 5
KV slot普通分页 Attention 的缓存槽C 的本轮 token → 45

它们不能互换。比如 idx_mapping 指向状态行，block_table 才把请求的逻辑块索引映射到缓存块。Attention 读取哪些历史缓存，还取决于序列长度等 metadata。

02 / 固定一个例子

同一轮：C 做 Decode，A 做 Prefill。

只讨论普通自回归生成、单个 Attention KV group、无投机、无并行、无 prefix 命中、无图 padding；kernel block size = KV block size = 4。这里的 Prefill 是请求阶段，不涉及 P/D 分离。

请求持久行已有状态本轮 qblock ids
C1prefill_len=3；computed=5；last_sampled=205；total_len=61[10,11]
A3prefill_len=4；computed=2；all_token_ids=[101,102,103,104]2[20]

C 的 205 已采样，但尚未作为模型输入计算 KV，所以它在 position 5。A 的 position 0、1 已算过，本轮继续输入 position 2、3。

04 / 对应真实代码

05 / 两种状态生命周期
InputBatch 对象会变，底层缓冲可以复用。
RequestState 管活跃请求的状态；InputBuffers 在初始化时分配 device 输入缓冲。每轮构造的 InputBatch 是描述本轮的对象，字段可以是这些长期缓冲的切片。因此“per-step InputBatch”并不表示每轮把所有 device tensor 重新分配一遍。
